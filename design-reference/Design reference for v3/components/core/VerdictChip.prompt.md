Mono-caps chip for machine judgments (verdicts, provenance); tone is inferred from the standard verdict words or forced via `tone`.

```jsx
<VerdictChip verdict="VALIDATED" />
<VerdictChip verdict="KILL" />
<VerdictChip verdict="RE-RANKED" tone="glacier" />
```

Standard mapping: VALIDATED/SHIP/KEPT moss · MISSED/KILL madder · REVISE ember · BY AGENT glacier · EVIDENCE THIN blossom · IN REVIEW marigold.
