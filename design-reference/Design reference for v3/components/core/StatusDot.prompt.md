Status dot + mono-caps word for the seven canonical states; color and motion tell the story before the word is read, but the word always ships.

```jsx
<StatusDot status="working" />
<StatusDot status="waiting" label="WAITING ON YOU" />
```

States: `working` (glacier pulse), `thinking` (blossom breathe), `waiting` (ember flare), `review` (marigold), `shipped` (moss), `blocked` (madder), `queued` (matte slate).
