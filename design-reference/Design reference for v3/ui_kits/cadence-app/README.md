# Cadence App UI kit

An interactive recreation of the Obsidian product shell: the 236px rail (mono
index 01-05, one ember badge, the shimmer working line, the Engine Room door),
plus three surfaces — Today (call queue + aurora + machine list), Discover
(evidence desk), and Build (mission cockpit). Press 1 / 2 / 4 to switch;
Approve, Send back, and Challenge show the voice-correct toasts.

Plan and Brain are intentionally stubbed (dimmed nav items). The complete
six-surface interactive prototype lives at the project root as
`Cadence App.dc.html`; this kit is the design-system-tokenized distillation
that composes the documented component anatomies.

Fidelity source: `Cadence App.dc.html` + `handoff/DESIGN-OBSIDIAN.md`.
