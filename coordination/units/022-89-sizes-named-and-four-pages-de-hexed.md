Unit 022: eighty-nine hand-written sizes become stops; four legal pages lose their last hexes

What was wrong: a completeness sweep found the size sweep that named 286
hand-written sizes had covered classes and components but not route inline
styles. Roughly 144 fontSize literals remained across public and admin
routes, each an unnamed number where a named stop should stand, plus nine
legal-page links painted a raw #ff9542 with no token behind it, plus demo's
CTA wearing the ember value as a literal while the page already spreads the
theme that defines --ember.

The snap rule was zero-delta by constitution: only values exactly equal to
a stop converted (89 did, via text-mrd-nano through text-mrd-display);
every off-scale value stayed untouched and is inventoried instead, about
fifty-three entries across both batches, each with file, line and the
element it serves. Those lists are the raw material for whichever ruling
names or retires the in-between sizes; nothing resized silently.

One conversion was blocked on principle: t.$slug's VerdictChip passes
fontSize 11, which equals the tiny stop, but the component forwards no
className. That fix belongs to Primitives.tsx, LANE 0's file, so it is
reported rather than reached across.

The four legal pages' links took var(--ember), which deepens the hue
slightly (#FF6B2C against the old lighter #ff9542) and clears AA at about
7:1 on the fixed dark canvas every one of them sits on. demo's CTA fill
became bg-[var(--ember)], identical pixels by definition. And the learning
block on /today now names its subject: About {opportunity_title} renders
above the evidence line when present (the builder corrected my brief here:
the field is snake_case on LearningRow; the camelCase name I cited lives on
a different response).

The ratchet caught the gains and refused to accept them until re-frozen;
four files left the raw-colour ledger entirely. Baseline moved down again.
