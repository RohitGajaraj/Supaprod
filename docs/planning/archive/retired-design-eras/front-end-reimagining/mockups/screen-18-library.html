The motion budget of this room
Class A · 0-120msHovers, filters, the scope switch, the kebab, the popover open (opacity only, no travel). The grid never animates a sort; it swaps settled.
Class B · 150-250msCard selection growth, new entries arriving (fade-up, 60-90ms stagger), the Ask summon. Reduced motion resolves to the finished frame.
Class C · none hereThe Library has no signature moment. Approval choreography belongs to the room; the shelf stays still so what was made reads as settled.
