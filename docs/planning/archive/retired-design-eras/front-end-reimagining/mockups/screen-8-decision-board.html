The spec's recommendation

Adopt A2, scoped exactly as the spec verdict states: working surfaces never; brand moments yes. The app-idle variant runs at roughly half landing density, far layer only, on workspace and product empty states, onboarding and tour frames, and the Brain at idle. It is removed, not dimmed, once the surface holds content, so ambient novelty can never compete with the machine-blue working presence.

B The color law: three voices, five tiers each spec §2

The verdict layer: state, never a voice
--verdict-pass
--verdict-fail

Badges, checks, and outcomes only. Never prose, chrome, or backgrounds. The amber working token is retired and deleted: working IS the machine speaking, so working states use the machine ramp and can never collide with memory gold again.

The four bans
  • ×No purple, violet, or indigo anywhere, charts and embeds included. It is the generic-AI tell of 2026.
  • ×No fourth voice. Verdicts have green and red, attention is ember, data numerals are machine blue.
  • ×Gold outside the memory grammar. No gold text, headings, or metrics.
  • ×Ember copy that skips the consequence. Every ember string says what approving sets in motion, or it is a bug.
