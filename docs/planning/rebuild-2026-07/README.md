# The 2026-07 rebuild

> _Created: 2026-08-04 · Last updated: 2026-08-04_

**This folder is live, not archive.** It holds the thinking behind the rebuild the founder ordered on 2026-07-28, and two documents that outrank most things written before them.

**Read the `FINAL-` file in each folder. The `a`/`b`/`c` files are the working papers behind it.** Ten topics were each investigated three ways and then synthesised; opening a working paper without its FINAL gets you one third of an argument.
