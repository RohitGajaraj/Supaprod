Quiet instrument

Graphite field, generous air, one living accent. Colour is rationed by importance: amber is the only hue allowed to glow, and it appears only where a human is needed. Four quiet hues carry state and never compete for the eye. Typography does the rest of the hierarchy.

Four laws hold it together. One amber fill per screen. One ripple and one sweep per surface. No text below 3:1 in either theme. Every clickable names where it goes and what it changes before you use it.

Tokens

Everything above is built from this set and nothing else. Two themes, one scale index: 0 is the most recessed surface, 10 is the highest contrast text, in both themes.

The set is three blocks, and the order is load bearing. First the raw scale and the literal compounds for dark, then the same list for light, then the semantic layer on :root, [data-theme]. That last selector is the whole trick: a custom property computes where it is declared, so a semantic alias declared only on the root resolves once, in the dark scale, and every light subtree quietly inherits it while its raw scale flips underneath. Name the theme scope and both themes are real. Skip it and light is a set of swatches nothing reads.

Steps 0 to 5 are surfaces and never carry text. Steps 6 to 10 are the text ramp, and the number under each one is its measured contrast against the panel. Nothing in the interface is allowed to sit below 3 to 1, which is why the old hash grey is gone.

Signal. The one living accent, and the only hue allowed to glow.

Meaning: a human is needed here, and nothing else ever borrows it. The law is one amber FILL per screen. Amber tint, edge and text may mark every place that waits on a person, which is how the rail badge, the gate card, the stalled agent and the unsaved row all read as one family. Exactly one of them is filled and glowing, and that one is the action to take next. A second filled amber object is a bug. Focus is the single exception, because only one element can hold focus at a time.

Dark separates surfaces by value and a 1px hairline, plus a 1px inset top highlight. Shadow is reserved for things that genuinely float. Light inverts that: shadows are soft and warm, hairlines are darker than the paper.

Motion. Four curves, four durations, and a rule for each.

e-std · .2,0,0,1state change, hover, entrance. The default.
e-out · .16,1,.3,1surfaces settling: drawers, popovers, route change.
e-in · .4,0,1,1exits only. Things leave faster than they arrive.
e-lift · .34,1.16,.64,1confirmation only: a gate cleared, a check turning green.
d-1 90ms hover and press feedback d-2 140ms colour and state d-3 220ms panel, popover, tab d-4 380ms large surface, route change d-amb 2600ms the gate breath d-sweep 2200ms work in flight

Nothing moves that is not reporting a change of state. Two ambient loops exist in the whole system, and the budget is one of each per surface: the amber breath on the item waiting for a human, and the blue sweep on the one track a person is actually watching. Five agents working produce five rows and one moving track, because a status dot per row multiplied by five is not information, it is an alarm. The spinner on a running check and the terminal caret are the same rule, one each. Everything stops under reduced motion.

Every interactive element in the file is one of these five heights. Focus is a 2px signal ring at 2px offset, on every interactive element, in both themes. Disabled is opacity 0.42 and nothing else, never a second grey. Icons are drawn on a 16 grid with the stroke set so the rendered weight is always 1.3px: 1.4 at 15, 1.5 at 14, 1.6 at 13, 1.9 at 11.

Rationale

The idea

Supaprod runs a machine that mostly does not need you. So the interface behaves like a measuring instrument: a graphite field, hairline structure, monospace numbers, and colour rationed by importance. One hue, a warm signal amber, is alive and it means one thing only, a human is needed here. Four low chroma hues carry state and never compete: blue for work in flight, green for verified, clay for fault, violet for memory and evidence. Every screen carries all five, so it is never grey, and exactly one amber object is filled, so the eye finds the decision before it reads a single word.

Why it reads premium

Brass on slate is an old and expensive pairing, and the dark and light themes are two materials rather than two brightness settings: the instrument body and the paper it prints on. Restraint is enforced by the token set, three faces, three weights, nine sizes, five curves, five control heights, one icon stroke weight. Numbers all live in one monospace face so every column aligns without a designer touching it. Separation comes from value and a 1px hairline instead of shadow, which is what keeps a five agent screen from looking like a pile of cards.

Living in it daily

Low fatigue is the point. One thing breathes and one track travels, per surface, no matter how many agents are running, so peripheral vision stays honest and the amber never becomes noise. The loop rail doubles as navigation and a status instrument, which means the answer to what is happening arrives in one glance from any surface. Density is safe because the pattern is rows and hairlines: adding a sixth agent adds a row, not a new moving object. The cost is discipline, a team that adds a second brand colour, a second filled amber, or a status animation per row breaks the whole promise.

Where it strains

Marketing moments have almost nothing to be loud with, so the public site needs its own extension of this system rather than a straight lift. Charts and multi series data will need a fifth and sixth hue, and the rule that colour equals meaning gets harder to hold there. Long celebratory moments, onboarding, a first successful ship, land quiet, so those need motion and typography to carry the feeling instead of colour. And on a bright screen in a bright room the four quiet hues sit close together, so state must always be carried by a word or a shape as well as by the hue.
