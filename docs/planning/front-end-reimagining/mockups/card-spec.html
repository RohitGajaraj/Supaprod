Founder gate 1 · addendum 1.1 · the card language, corrected

Every card, one grid

A card is a plain ink surface: hairline border, token radius, nothing decorative. Inside, one internal grid, always in the same order: the chip row names who and when, the body says what, evidence chips ground it, the action row holds the verbs. Voice and attribution ride the chips and the content, never the card surface. Colored edge strips are gone from the entire mockup set.

A
Chip row
Label chips left. One timestamp, mono, right-aligned. Never floating mid-content.
B
Body
Prose with mono counts that inherit the line, so numbers never break flow.
C
Evidence chips
Optional. Artifact ids and track records, mono, hairline-bordered.
D
Action row
The verbs, keys inline. On a gate, this row and the chip are where ember lives.

Retired from every card, per the founder's red-lines
✕Colored edge strips and highlighter bars, on any card, in any voice. The gold memory tick, the ember queued tick, and the gate card's ember wash and border are all gone.
✕Floating timestamps. The one timestamp is mono, right-aligned, in the chip row; times inside prose exist only when the time is the fact the sentence states.
✕Numbers that break line flow. Inline mono counts inherit the sentence's size and line height everywhere.
✕Heavy card shadows. Depth comes from layering and hairlines; the active tray card is marked by its ember border alone.
These four specimens use the byte-identical shared stylesheet every screen carries, with the Helio Labs content world. Any card in any mockup that does not reduce to this grid is a bug against Addendum 1.1.
