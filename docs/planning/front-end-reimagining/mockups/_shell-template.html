SPEC-52 · from BET-31

Saved replies for Relay

Teams on Relay answer the same questions every day. Saved replies give a workspace a shared library of reusable answers with variables, cutting first response time without another tool in the stack.

Requirements (4 of 9)
  • R1A workspace library of saved replies with variables for customer name and plan.
  • R2Insert from the reply composer with a two-key shortcut.
  • R3Usage counts per reply so teams can prune the dead ones.
  • R4Permissions: admins edit the library, everyone inserts.

+ 5 more

Grounding
Assumes reply templates live per workspace, not per user: of the 214 tickets behind this bet, 61 asked for shared answers, 9 for personal ones.
Open questions (2)

  • Q2Cap the library size at launch, or trust pruning?
