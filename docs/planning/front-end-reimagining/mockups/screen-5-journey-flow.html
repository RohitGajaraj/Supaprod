Bulk CSV import for Atlas

  • R2Dry run first: a preview of the first 100 rows with every validation error named.
  • R3Imports run in the background and post a receipt with a row count and a skip list.
  • R4Every import is reversible for 24 hours as one action.

  • A2CSV covers most historical data; API import can wait. Watching the ticket mix.
  • A350MB covers the p95 file. Watching upload failures; the Critic's one caution.
Outcome contract
Landed means: within 30 days of ship, half of new enterprise trials run an import in week one. Check-by date: August 24.
