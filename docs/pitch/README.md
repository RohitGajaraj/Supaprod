## The routing doctrine (standing rule, founder 2026-07-10 — wired into CLAUDE.md + AGENTS.md)

**Any session that produces outward-facing positioning content — differentiation narratives, USP arguments, pitch language, demo flows, objection answers, investor/application material — routes the distilled result INTO this folder in the same session** (update the existing file; never create parallel copies). The deep reasoning stays in the strategy corpus; this folder holds the founder-ready distillation with pointers back. Rules that govern everything here:

1. **Honesty is the product.** Every claim carries its wiring status: PROVEN (live, verifiable) · CLAIM-ON-WIRING (built, not yet demonstrably run — never said publicly until it runs) · ASPIRATION (roadmap, say so).
2. **Cite artifacts and companies, never gurus** (research §12.4 — the community's seller-allergy is our tailwind).
3. **Numbers must trace to the live DB or a dated source.** No run-rate theater (investors' own red flag, research §17).
4. Update-in-place; the git history is the version trail.
